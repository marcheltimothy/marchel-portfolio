# Marchel Mercado Portfolio

Static portfolio made with separate HTML, CSS, and JavaScript files.

## Files
- index.html
- style.css
- script.js
- images/

## Important
Keep `index.html`, `style.css`, and `script.js` in the same folder. Open `index.html` after extracting the ZIP.

## GitHub Pages
Upload the files to a GitHub repository, then go to Settings > Pages and select the `main` branch and root folder.

Replace the placeholder email and GitHub profile link in `index.html` before publishing.
